This enhancement pack adds basic functionality for discovering Cisco firewalls.  Cisco firewalls must be discovered via the SNMP sysObjectID, as ServiceNow discovery provides no mechanism for classifying them as a firewall based on general MIB-2 data (as of Fuji).  This enhancement pack ships with several defined sysObjectID classifiers for devices known to be firewalls.  If additional models are needed they can easily be added to the SNMP System OID's list.  This enhancement pack uses the out of box cmdb_ci_ip_firewall class provided by ServiceNow, and just adds a classifier and related objects to discover firewalls and create CI's for them in that class.
